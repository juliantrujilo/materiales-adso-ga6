Esta Guía de Estudio es un paso a paso para seguir con las manos en el teclado. Cómo trabajar con esta guía (siempre igual)

  1. Lee la explicación corta del paso.
  2. Crea o abre el archivo que se indica en Visual Studio Code.
  3. Presiona el botón «Copiar código» de la caja y pégalo en tu archivo (Ctrl + V).
  4. Guarda con Ctrl + S y mira el resultado en el navegador (F5 para recargar).
  5. Revisa la caja verde «Verifica que funciona» y marca el paso como hecho. Tu avance queda guardado en este navegador.

Tus herramientas

Visual Studio Code (el editor donde escribes). Abre una carpeta con File → Open Folder. Para crear un archivo: clic derecho en el panel izquierdo → New File y escribe el nombre completo, por ejemplo index.html. Para crear una carpeta: New Folder.
Un navegador (Chrome, Edge o Firefox). Para ver tu página, haz doble clic en index.html. Después de cada cambio: guarda en el editor y presiona F5 en el navegador (o Ctrl + F5 si no ves el cambio).
Tres reglas que evitan el 90 % de los errores:
• Nombres de archivos y carpetas en minúsculas, sin espacios ni tildes (tema1.html, no Tema 1.html).
• Las rutas son relativas: css/estilos.css, nunca C:\Users\....
• Cada vez que cambies algo: Ctrl + S en el editor y F5 en el navegador.

Crea la carpeta del tutorial y sus archivos

Tiempo estimado: 5 min

Un sitio web es un conjunto de archivos ordenados en carpetas. Vas a crear la estructura completa vacía y luego la irás llenando paso a paso.

tutorial/ ├── index.html ← página de inicio: título + lista ordenada ├── tema1.html ← una página por cada concepto ├── tema2.html ├── tema3.html ├── css/ │ └── estilos.css ← los estilos de todas las páginas └── img/ ← una imagen por tema
  1. Crea en tu Escritorio una carpeta llamada tutorial y ábrela en Visual Studio Code (File → Open Folder).
