Bloque 1 · Contexto · Las 3 capas de una página web

¿Cómo funciona una página web? Tres capas que trabajan juntas

Toda página web se construye con tres lenguajes, y cada uno tiene un trabajo distinto. Piensa en una casa: HTML son las paredes y puertas (la estructura), CSS es la pintura y los muebles (la apariencia) y JavaScript es la instalación eléctrica que hace que el timbre suene cuando lo presionas (el comportamiento).

1 · Solo HTML

Laptop Gamer RTX 4070

$4.999.000

Está la información, pero sin diseño. Es el esqueleto.

2 · HTML + CSS

Laptop Gamer RTX 4070

$4.999.000

Los mismos elementos, ahora con colores, bordes y espacio.

3 · HTML + CSS + JS

Laptop Gamer RTX 4070

$4.999.000

Carrito: 0

Pruébalo: haz clic en el botón. JavaScript reacciona.

Estructura

HTML

Es un lenguaje de marcado: encierras el contenido entre etiquetas que dicen qué es cada cosa (un título, un párrafo, una imagen, un enlace). No programa nada: solo describe.

Apariencia

CSS

Son reglas de estilo: dices a qué elementos aplican (selector) y cómo se ven (propiedad: valor). Por ejemplo, «todos los botones, fondo azul». Controla colores, tamaños, espacios y la disposición.

Comportamiento

JavaScript

Es un lenguaje de programación: la página reacciona a lo que haces (un clic, enviar un formulario) y cambia sin recargarse. Valida datos, abre menús, muestra mensajes.

Cómo se reparte en tus evidencias

Bloque 1 · Contexto · Anatomía de una página HTML

Anatomía de una página: cada zona tiene su etiqueta

Una página no es un bloque único: se divide en zonas con un significado. HTML tiene una etiqueta para cada zona (a esto se le llama HTML semántico). Usar la etiqueta correcta ayuda a los buscadores, a los lectores de pantalla y a ti mismo cuando vuelves a leer tu código.

EtiquetaSignificaÚsala para...
<header>EncabezadoEl logo o título del sitio y, normalmente, el menú
<nav>NavegaciónUn grupo de enlaces para moverse por el sitio
<main>Contenido principalLo más importante de la página. Solo hay uno por página
<section>SecciónUn tema con su propio título (bienvenida, catálogo, «quiénes somos»)
<article>ArtículoUna pieza independiente que podrías mover a otro lugar: una tarjeta de producto, un tema del tutorial
<footer>Pie de páginaContacto, derechos y enlaces finales
Bloque 1 · Contexto · El esqueleto de todo archivo HTML

El esqueleto: lo que lleva TODA página HTML

Todas las páginas empiezan igual. Hay una parte que no se ve (el <head>: configuración) y una que sí se ve (el <body>: tu contenido). Memoriza esta estructura: es la plantilla de cada archivo .html que crearás hoy.

esqueleto.htmlHTML
1<!DOCTYPE html>
2<html lang="es">
3<head>
4 <meta charset="UTF-8">
5 <meta name="viewport" content="width=device-width, initial-scale=1.0">
6 <title>Título que aparece en la pestaña</title>
7 <link rel="stylesheet" href="css/estilos.css">
8</head>
9<body>
10 <header>...</header>
11 <main>...</main>
12 <footer>...</footer>
13 <script src="js/main.js"></script>
14</body>
15</html>
Qué hace cada parte, línea por línea
Línea 1

Le dice al navegador que este archivo es HTML5. Va siempre en la primera línea.

Línea 2

Declara que la página está en español. Ayuda a los lectores de pantalla a pronunciar bien.

Línea 3

Zona invisible: configuración de la página. Nada de lo que pongas aquí se dibuja en pantalla.

Línea 4

Codificación UTF-8: permite escribir tildes y la ñ sin que salgan caracteres raros.

Línea 5

Hace que la página se ajuste al ancho del celular. Sin esta línea, el diseño móvil no funciona.

Línea 6

El texto de la pestaña del navegador.

Línea 7

Conecta tu archivo de estilos CSS. La ruta es relativa a este archivo.

Línea 9

Zona visible: aquí va todo lo que el usuario ve.

Línea 13

Conecta el JavaScript. Va al final del body para que el HTML ya exista cuando el código lo busque.

Bloque 1 · Contexto · Archivos y carpetas conectados

Cómo se conectan los archivos entre sí

Un sitio web es un conjunto de archivos que se enlazan unos a otros. Cada conexión usa una etiqueta distinta y una ruta relativa: la dirección del archivo contada desde el archivo donde estás escribiendo, no desde tu disco duro. Por eso tu proyecto funciona igual en cualquier computador.

Ejemplo

Carpeta de tu proyecto

techstore-html/
  index.html ← página principal
  login.html
  css/
    estilos.css
  js/
    main.js
  img/
    laptop.svg

Reglas de oro

Nombres de archivos

• Todo en minúsculas.
• Sin espacios ni tildes: tema1.html, no Tema 1.html.
• La extensión importa: .html, .css, .js.
• Una carpeta por tipo de archivo: css/, js/, img/.

Para conectar...EtiquetaEjemploDónde va
Hoja de estilos<link>href="css/estilos.css"Dentro del <head>
JavaScript<script>src="js/main.js"Al final del <body>
Otra página<a>href="login.html"Donde quieras el enlace
Una imagen<img>src="img/laptop.svg"Donde quieras la imagen
El error número 1 de principiantes
Una imagen o un estilo que «no carga» casi siempre es una ruta mal escrita: una mayúscula de más, una tilde, una carpeta que falta o una extensión equivocada (.jpg vs .jpeg). Revisa la ruta letra por letra.

Bloque 2 · EV01 · Paso 4

Paso 4: dale estilo con CSS (css/estilos.css)

Hasta ahora tu tutorial se ve como un documento en blanco y negro. CSS son reglas con esta forma: selector { propiedad: valor; }. El selector dice a qué elementos aplica (h1 son todos los títulos, .indice es todo lo que tenga class="indice") y cada propiedad cambia un aspecto.

tutorial/css/estilos.cssCSS

2:root { --azul: #2563eb; --texto: #334155; }
3
4* { margin: 0; padding: 0; box-sizing: border-box; }
5
6body {
7 font-family: Arial, sans-serif;
8 color: var(--texto);
9 line-height: 1.7;
10}
11
12main { max-width: 820px; margin: 0 auto; padding: 32px 20px; }
13
14h1 { color: #1e293b; margin-bottom: 12px; }
15
16.imagen-tema { width: 100%; height: auto; border-radius: 12px; }
17
18.indice li { margin: 0 0 12px 22px; }
19.indice a { color: var(--azul); font-weight: 700; }
Qué hace cada parte, línea por línea
Línea 2

Variables CSS: guardas un color una vez (--azul) y lo reutilizas con var(--azul). Si luego quieres otro azul, lo cambias en un solo lugar.

Línea 4

El asterisco aplica a todos los elementos. Quita los márgenes por defecto del navegador y hace que el ancho incluya el relleno (box-sizing), lo que evita desbordes.

Línea 6

Estilo base de toda la página: tipo de letra, color del texto y separación entre líneas (line-height) para leer cómodo.

Línea 12

max-width limita el ancho del contenido; margin: 0 auto lo centra; padding deja aire en los bordes.

Línea 14

Todos los títulos principales quedan en azul oscuro y con espacio debajo.

Línea 16

Un selector de clase (empieza con punto): afecta a lo que tenga class="imagen-tema". La imagen ocupa todo el ancho sin deformarse.

Línea 18

Separa cada elemento de la lista ordenada. Un selector con espacio significa «los li que están dentro de .indice».

Así debería verse
Un contenido centrado y cómodo de leer, títulos oscuros, enlaces azules en negrita, la lista numerada con espacio entre elementos y la imagen del tema ocupando todo el ancho. Si no ves ningún cambio, revisa la línea <link rel="stylesheet"> de tus páginas.

EV02: qué es un componente y cómo encontrarlos en tu proyecto

Un componente es una pieza de la interfaz con una función clara y que suele repetirse: el encabezado se repite en todas las páginas, la tarjeta de producto se repite una vez por cada producto. Tu documento EV02 explica cuáles son los componentes de tu proyecto y con qué etiquetas HTML se construyen. Observa tu página de inicio de TechStore Pro: cada número es un componente.

Bloque 4 · EV03 · Paso D

Paso D: la página de login (un formulario usable)

Un formulario es usable cuando cada campo tiene su etiqueta y el usuario sabe qué escribir. La clave es el par <label for="correo"> + <input id="correo">: el for de la etiqueta debe ser igual al id del campo; así, al hacer clic en el texto, el cursor entra al campo. Debajo de cada campo dejas un párrafo vacío donde JavaScript escribirá el mensaje de error: es tu pantalla de error del diseño.

Bloque 4 · EV03 · Paso E

Paso E: diseño adaptable (responsive) con media queries

Tu página se verá en pantallas muy distintas: monitores, tabletas y celulares. Un diseño adaptable reorganiza el contenido según el ancho disponible. Se logra con media queries: reglas CSS que solo se aplican cuando la pantalla mide tanto o menos. Este es el mismo catálogo en tres anchos:

css/estilos.css (al final del archivo)CSS
1/* TABLETA: 900px o menos, el catálogo pasa a 2 columnas */
2@media (max-width: 900px) {
3 .grid-productos { grid-template-columns: repeat(2, 1fr); }
4}
5
6/* MÓVIL: 600px o menos */
7@media (max-width: 600px) {
8 .grid-productos { grid-template-columns: 1fr; }
9
10 .menu-toggle { display: inline-block; } /* aparece el botón Menú */
11 header nav { display: none; } /* el menú se oculta */
12 header nav.abierto { display: flex; } /* y JS lo muestra */
13}
Qué hace cada parte, línea por línea
Línea 2

«Si la pantalla mide 900 px o menos, aplica lo que está entre llaves.» Es el punto de corte de la tableta.

Línea 3

El catálogo pasa de 3 columnas a 2: repeat(2, 1fr) crea dos columnas de igual ancho.

Línea 7

Punto de corte del celular.

Línea 8

Una sola columna: las tarjetas se apilan, una debajo de otra.

Línea 10

El botón «Menú» estaba oculto en escritorio (display: none en tu CSS base); en móvil se vuelve visible.

Línea 11

El menú se esconde para ahorrar espacio...

Línea 12

...y se muestra cuando JavaScript le agrega la clase abierto. Esa es la conexión entre CSS y JS.

No olvides
En tu CSS base el botón del menú debe empezar oculto: .menu-toggle { display: none; }. Si no, se verá también en el computador.
