APLICACIÓN PRÁCTICA EN EL PROYECTO FORMATIVO

Proyecto Transversal: TechStore Pro React

Las evidencias de la Guía 6 no son ejercicios aislados: cada entregable construye una parte del e-commerce formativo del programa:

MySQL Workbench

Capa Relacional SQL

Diseño normalizado para la gestión transaccional de usuarios, roles, pedidos, detalle de facturación e inventario con integridad de claves foráneas.

  • Esquema DDL con ON DELETE RESTRICT
  • Consultas DML con INNER JOIN complejas
MongoDB Compass

Capa Documental NoSQL

Colecciones dinámicas de productos tecnológicos con especificaciones variables por categoría, imágenes anidadas y logs de auditoría.

  • Documentos JSON/BSON sin esquema rígido
  • Operaciones CRUD demostradas en video
Figma + Web UI

Capa Visual Front-End

Prototipado en Figma y maquetación web responsiva de la tienda: catálogo, carrito de compras, checkout y dashboard administrativo.

  • Componentes modulares accesibles
  • HTML5 semántico y CSS3 responsive
