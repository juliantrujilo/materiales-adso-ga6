Sentencias DML y Exportación del Script SQL Físico

Cierre del bloque relacional: Inserción, actualización, eliminación, consultas complejas con JOINs y exportación final del script .sql ejecutable (EV03).

-- Ejemplo DML: Insertando datos semilla y consultando con JOIN
INSERT INTO productos (sku, nombre, precio, stock, id_categoria) 
VALUES ('LAP-001', 'Laptop Gamer Pro', 4500000.00, 10, 1);

SELECT p.nombre AS producto, c.nombre AS categoria, p.precio
FROM productos p
INNER JOIN categorias c ON p.id_categoria = c.id_categoria
WHERE p.precio > 1000000;
