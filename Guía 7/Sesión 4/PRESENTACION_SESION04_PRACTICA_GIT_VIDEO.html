Bloque 3 · Paso 1 · Crear el repositorio remoto

Paso 1: crea el repositorio público Programa-Git en GitHub

El primer punto de la guía es crear un repositorio nuevo, público, con el nombre exacto Programa-Git. Se hace desde el navegador.

  1. Entra a github.com con tu sesión iniciada y abre el menú + (arriba a la derecha) → New repository.
  2. Nombre del repositorio: escribe exactamente Programa-Git (respeta mayúscula y guion).
  3. Visibilidad: marca Public. La guía pide un repositorio público.
  4. Déjalo vacío: NO marques Add a README, .gitignore ni licencia, porque tu repositorio local ya tiene su primer commit.
  5. Presiona Create repository y copia la URL HTTPS de la sección Quick setup (termina en .git). La guía dice «copiar su url con el protocolo https».
Qué obtienes

Una dirección como https://github.com/TU_USUARIO/Programa-Git.git. En el siguiente slide la usas con git remote add.

Error frecuente

Crear el repositorio con README y luego recibir rejected ... fetch first o unrelated histories al hacer push. Si te pasa, crea un repositorio vacío nuevo (o ábrelo en Settings, elimínalo y créalo de nuevo).

Qué te llevas para tu video EV05: en el video, enseña la pantalla de creación con el nombre Programa-Git y la opción Public marcadas, y la URL que copias (indicador 3).

Errores frecuentes y cómo resolverlos

Si algo falla mientras grabas, no pasa nada: para, resuelve y vuelve a grabar esa parte. Casi siempre es una de estas causas.

Error o mensajeCausa más comúnSolución
'origin' does not appear to be a git repositoryTu remoto tiene otro nombre (por ejemplo github)Revisa con git remote -v y usa ese nombre, o renómbralo con git remote rename github origin
src refspec main does not match any (o master)No hay commits o escribiste el nombre de rama equivocadoHaz el primer commit y revisa git branch
remote origin already existsYa habías añadido el remotoRevisa git remote -v; si la URL es errónea, usa git remote set-url origin URL
Authentication failed / Support for password authentication was removedUsaste la contraseña de la cuenta en lugar de Credential Manager o tokenRepite el push y autoriza en el navegador, o pega un token (Sesión 3, slide 11)

nothing to commit, working tree cleankotlin.txt no está en la carpeta del repositorio, o ya lo guardasteComprueba con ls (o dir) que existe dentro de Programa-Git
