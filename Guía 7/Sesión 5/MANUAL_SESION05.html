La evidencia GA7-220501096-AA1-EV02 se llama «Definir estándares de codificación, de acuerdo con la plataforma de desarrollo elegida». Modelo · 4 Configuración de herramientas
El estándar se hace cumplir con ESLint, que revisa la calidad del código y las reglas de React y de hooks, y con Prettier, que aplica el formato definido en .prettierrc (comillas simples, punto y coma, 2 espacios y 80 columnas). EditorConfig mantiene la misma indentación y fin de línea en cualquier editor. Los archivos de configuración están en la raíz del repositorio, de modo que todo el equipo usa las mismas reglas.
Verifica con tu versión: el nombre de las reglas y de las configuraciones recomendadas de los plugins puede cambiar entre versiones. Prettier lee .editorconfig y lo que pongas en .prettierrc manda; mantén los mismos valores en ambos. La fuente de verdad es la documentación de lo que instalaste.

1.4 Versionamiento local y remoto

El versionamiento local ocurre en el equipo de cada desarrollador, donde Git registra los cambios sin internet. El remoto ocurre en GitHub, que aloja una copia del repositorio para respaldarla y compartirla. Se conectan con git push.

Git (local) y GitHub (remoto). Ramas feature/ y fix/, commits Conventional Commits y pull requests revisados.
